## 1. Phosphor Icons

**Licence.** Phosphor Icons v2.0.8 (`@phosphor-icons/core`) by Helena Zhang
and Tobias Fried is under the **MIT licence** ("Copyright (c) 2023 Phosphor
Icons").
- It is free for personal and commercial use.
- It may be bundled, modified and redistributed inside any software, free or
  paid.
- The only condition is to keep the copyright and licence notice with the
  icons.
- There are no paid tiers for the icons themselves. (Phosphor's paid
  products are separate Figma/design-tool offerings.)

**Files.**
- The full set is in `~/projects/assets/Icons/phosphoricons`: 1,248 icons ×
  6 weights (regular, thin, light, bold, fill, duotone), plus `LICENSE`,
  `SOURCE.txt` (checksum) and `INDEX.txt` (names, categories, search tags).
- The app copies only the icons it uses, in the **regular** weight, to
  `resources/icons/phosphor/regular/`, with the `LICENSE`.

**How.**
- `util_icons` keeps its API (`icon_pixbuf`, `icon_image`, `icon_button`,
  `icon_label_button`). It now reads Phosphor SVGs, which use a 256 × 256
  viewBox and `currentColor`, and recolours them to the theme as before.
- The Heroicons files leave the app, and About → Credits names Phosphor
  instead. Heroicons stay in the assets folder for reference.

**Icon map.**

| Function | Phosphor icon |
|---|---|
| Rotate left | `arrow-counter-clockwise` |
| Rotate right | `arrow-clockwise` |
| Rotate 180° | `arrows-clockwise` |
| Delete page | `file-x` |
| Clear all | `trash-simple` |
| Move left / right | `arrow-left` / `arrow-right` |
| Zoom out / in / fit | `magnifying-glass-minus` / `magnifying-glass-plus` / `arrows-in` |

| Quick Edit: delete item / apply to all pages | `trash` / `copy` |
| Add fonts (upload) / create | `upload-simple` / `plus` |

**Hover captions.** Every icon button has a tooltip with its name and
shortcut (for example "Rotate left (90° anticlockwise)"). GTK shows it after
a short hover and hides it when the pointer leaves.

## 2. Preview actions

The text buttons become one row of icon buttons with tooltips:
- **Page** group: rotate left, rotate right, rotate 180°, move left, move
  right.
- **Remove** group: delete page (`file-x`) and clear all (`trash-simple`).

A thin separator divides the groups. The feature buttons (Quick Edit…,
Import images…) keep their labels; **Save** / **Save As…** stay on the right.

## 3–5. Scan page

**Detect Scanner** (was "Scanner"):

```
Detect Scanner
[Find] [ Epson ES-400II (epsonds (+1 more))    ▾ ] (✓) [Devices]
```

- **Find** (was "Refresh") comes first, and runs the full search. The
  spinner turns in its place while searching.
- **✓** is the Phosphor `check` in green, shown only when the scanner has
  answered ("Scanner Found"). It is hidden while searching or on a problem.
- "Device info" becomes **Devices**, matching the sidebar.

**Options: uniform layout.**
- Every row has the same label column (130 px) and a control column
  starting at the same x.
- Every segmented button has the **same width** (a shared minimum wide
  enough for the longest label, "One sheet at a time"), so the choices line
  up in columns across rows: Scan Type, Sheets, Color, Quality, Blank Pages.
- `SegmentedControl` gets a `button_width` argument; the Scan page passes
  one shared value.

**Blank Pages: Keep / Remove** ("Remove blank pages" is the usual term;
"blank" also covers pale-coloured sheets, which "white" wouldn't).
- It is a shortcut for the Blank-page removal module: the same switch as
  Settings → Features, and both stay in sync (`features-changed`).
- The row is hidden if the module is removed.

**Document Size** (was "Paper size"): the same grouped list, with the combo
at half the width of the options area instead of stretching across it.

## 6. Button text size

The sidebar labels are 10 pt. Button labels become 10 pt as well
(`button label`, `.segment button label`, `.primary-pill label`), so no
button text is bigger than the sidebar's. Buttons stay 28 px tall, the
sidebar row height.

## 8. App icon in Alt+Tab and the panel

**Cause.** The window's class came from the script name (`WM_CLASS
"main.py"`), which matches no menu entry. The window also had no
`_NET_WM_ICON`, so Cinnamon had nothing to show.

**Fix.**
- `GLib.set_prgname("linscanner")` and `Gdk.set_program_class("linscanner")`
  run before any window exists, giving `WM_CLASS "linscanner"`.
- The menu entry gets `StartupWMClass=linscanner` and `Icon=linscanner`.
- `install.sh` installs the icon as
  `~/.local/share/icons/hicolor/512x512/apps/linscanner.png`, and uninstall
  removes it.
- The window and every dialog get an icon list at 16–256 px
  (`Gtk.Window.set_default_icon_list`).
- Verified with `xprop`: `WM_CLASS "linscanner"`, and `_NET_WM_ICON` present.

## 9. Signature fonts: licensing

**Rule (from the user).** Bundle a font only if it is free with no
ambiguity. A font is excluded if its terms forbid use in software, or
restrict it (for example, personal use only). The word "bundle" in font
licences usually means font *collections* sold together, not software, and
doesn't exclude a font by itself.

**Checked 2026-09-21:**
- the readme and `info.txt` files in each zip;
- the name tables inside the font files;
- the designers' licence pages (Khurasan);
- the FontSpace pages;
- the Creatype FAQ.

| Font | Designer | Terms found | Decision |
|---|---|---|---|
| **Arkipelago** | Nasir Udin | FontSpace "Freeware"; no restrictions anywhere | **Bundle** |
| **Julia Lauren** | Fenny Wiryani (starinkbrush) | "Freeware"; no restrictions | **Bundle** |
| **Paul Signature** | Cundrawan (cove703) | "Freeware"; no restrictions | **Bundle** |
| **Sandra Belhock** | Cundrawan (cove703) | "Freeware"; no restrictions | **Bundle** |
| High Empathy, Opencare, Patung, Royalty Free, Tirelessly Love You | Khurasan | "100% free for personal & commercial use". Khurasan's licence page sells a separate **App / Game License** ("1 App"), and its Free License tier doesn't include apps | Not bundled: app use is licensed separately |
| Bailey Signature | Creatype Studio | "100% FREE for COMMERCIAL USE". The store FAQ: "You are not allowed to share files you download … or make available fonts for download" | Not bundled: sharing the file is forbidden |
| Othere | Khurasan | "free for personal use" only; commercial use is paid | Not bundled |
| Neumartha | zamjump | "demo font … PERSONAL USE ONLY" | Not bundled |

The **9 SIL OFL fonts** already bundled (Alex Brush, Allura, Great Vibes,
Herr Von Muellerhoff, Monsieur La Doulaise, Mr Dafoe, Mrs Saint Delafield,
Pinyon Script, Sacramento) stay. The OFL explicitly allows bundling and
redistribution with software, so it is the least ambiguous licence of all.

The bundled set is therefore **13 fonts**: 9 OFL and 4 freeware.
- The freeware fonts get the same `fonts.json` credit entries, with
  `"license": "Freeware (FontSpace)"` and the source link.
- The About page lists all 13 with their designers.
- Fonts that aren't bundled can still be added by each user on their own
  computer (Create Signature → Add fonts…), under their own licence terms.

**Follow-up #33** is rewritten to cover only the fonts we ship:
- thank the authors;
- for the 4 freeware fonts, ask for written confirmation that bundling in
  free software is fine;
- donate where a link is offered.
Everything else in #33 is removed.
